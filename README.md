
# EDA: Brazilian E-Commerce (Olist)

**Автор:** Крайних Анастасия
**Стек:** Python, pandas, seaborn, matplotlib, scipy  
**Датасет:** [Brazilian E-Commerce — Kaggle](https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce) — 100k заказов, 9 таблиц

[Ноутбук](https://github.com/akrainih/olist-eda-analysis/blob/2b4d334c55df3309756c2862fe897b2c4a9e00f0/EDA_brasil.ipynb)

## Цель

Исследовать операционные показатели маркетплейса: динамику продаж,
географию покупателей, топ категории и влияние доставки на оценки.

----

## Ключевые выводы

| Инсайт | Цифра |
|--------|-------|
| Рост платформы за год | x40 |
| Топ штат по выручке | SP  |
| Топ категория | bed_bath_table |
| Оценка при быстрой доставке | 4.4 vs 2.8 при опоздании |
| Доля опоздавших заказов | 6.4% |

---

## Структура анализа

1. Загрузка и объединение 9 таблиц (merge)
2. Очистка данных
3. Динамика продаж по месяцам и дням недели
4. География: топ штаты по заказам и выручке
5. Топ категории товаров
6. Анализ доставки и влияние на оценки (t-test)
